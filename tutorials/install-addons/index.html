Description

Instructions

Reminder: NEVER download .exe or .msi files!

  1. Open the link in the description

    Head to the trusted mod and add-on sites list.

  2. Pick a site you trust

    Choose one of the listed sources, then search for a mod or add-on you like.

  3. Download it

    Only download .mcaddon, .mcpack, or .mcworld files. Be cautious with .zip files unless they are from an official or trusted source. If you download a .zip file from a trusted source, right-click it, then select Extract All > Extract to get the .mcaddon, .mcpack, or .mcworld file(s).

  4. Open the file with Minecraft Education

    Find the download in File Explorer, right-click it, choose Open with, then pick Minecraft Education.

  5. Create or copy a world

    In Minecraft Education, go to Play › My Worlds › New World. If you want to use an existing world, select the world, then choose Manage › Copy. Select the copied world and open Settings.

  6. Turn on the behaviour pack

    Scroll down to Behaviour Packs and activate the pack you downloaded.

  7. Turn on the resource pack

    If the add-on came with one, do the same under Resource Packs.

  8. Press play

    Load the world and enjoy your new mod!

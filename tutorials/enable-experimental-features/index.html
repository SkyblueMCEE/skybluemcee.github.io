How to Enable Experimental Features in Minecraft Education

Video, useful links, and instructions in one adjustable workspace.

Description

Follow this tutorial if you want to enable Experimental Features in your Minecraft Education world!

Links

  • Minecraft World Settings Editor →

Instructions

  1. Open your worlds

    In Minecraft Education, select Play › My Worlds.

  2. Export the world

    Select the world you want to change, choose Manage › Export, and save the .mcworld file somewhere you can easily find it.

  3. Open the World Settings Editor

    Go to the Minecraft World Settings Editor.

  4. Choose your exported world

    Click the cloud labelled Drop your .mcworld here (Click me!). In the file window, find the world you just exported and double-click it.

  5. Enable the required experiments

    Open the Experiments tab and turn on the experiments you need. If you are installing an add-on, check its download page or instructions to find out which experiments it requires.

  6. Save a modified copy

    Click Save a new copy. Your original exported file will remain unchanged.

  7. Complete the Linkvertise page

    Click Get link, watch the ads, choose Continue, use Skip ad three times, and then click Open. Do not install or download anything offered by an advertisement.

  8. Download the modified world

    When you return to the editor, click the download button to save the modified .mcworld file.

  9. Import it into Minecraft Education

    Find the modified world in File Explorer, right-click it, choose Open with, and select Minecraft Education.

  10. Open your world

    Your imported copy is ready to use with the selected Experimental Features enabled!

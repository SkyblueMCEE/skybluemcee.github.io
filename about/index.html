About SkyblueMC

Practical Minecraft Bedrock and Education tools, guides, and videos made for players and creators.

The website

Free tools that solve real Minecraft problems

SkyblueMC is an independent Minecraft creator. This website brings together browser-based tools, safety-focused guides, and tutorial videos for Minecraft Bedrock Edition and Minecraft Education.

The World Settings Editor was created to make settings inside exported .mcworld files easier to inspect and change. World files are processed locally in the browser and are not uploaded to SkyblueMC.

How it is made

Original tools and tested guidance

The website and its tools are built and maintained by SkyblueMC. Guides are written to be understandable for everyday players and are updated when Minecraft or the website changes.

The source code is public on GitHub so visitors can inspect how the tools work, report bugs, and suggest improvements.

Funding and recommendations

How the site supports itself

Some World Settings Editor downloads use a Linkvertise page, and SkyblueMC may earn money when visitors complete that step. The modified world remains in the visitor's browser and is not sent to Linkvertise.

Recommended websites are selected for usefulness and relative safety, not because every community upload can be guaranteed safe. Paid placements, sponsorships, or affiliate relationships will be clearly disclosed where they appear.

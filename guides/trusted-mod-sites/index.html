Safety & compatibility information
Download safely

Check these things before opening a file

  • Read the address bar. Scam sites often copy a trusted site's name with a different ending or misspelling.
  • Expect Minecraft files. Add-ons normally arrive as .mcaddon or .mcpack; maps may use .mcworld. Some creators use .zip, but an add-on should not require an .exe or .msi installer.
  • Check the creator and update date. Prefer the original creator's page, recent files, clear installation instructions, and useful comments or reviews.
  • Do not grant unrelated permissions. A pack download does not need browser notifications, a browser extension, remote access, or your Microsoft password.
  • Scan unexpected files. Keep Microsoft Defender or another reputable security tool enabled. Cancel the download if the file is not what the page promised.
  • Back up your world. Even a harmless add-on can break a world when it is outdated or incompatible.

About ad pages: An ad or link-shortener page does not automatically mean the add-on is malicious. Never install anything or grant permissions on that page, though—the final download should still be the expected Minecraft pack or world file.

No community download site can guarantee every upload is safe. These recommendations reduce risk; they do not replace checking the file and creator yourself.

Warning signs

Leave the page if it asks you to…

  • Download an executable “mod installer,” “Minecraft updater,” or unknown app.
  • Install a browser extension or allow notifications before you can download.
  • Enter your Microsoft, school, Minecraft, Discord, or email password.
  • Disable antivirus protection or ignore a malware warning.
  • Download a Java .jar file for Minecraft Education or Bedrock.
Education compatibility

A safe add-on can still be incompatible

  • Compare the add-on's supported Bedrock version with the version shown in Minecraft Education.
  • Install both the behavior pack and resource pack when the creator provides both.
  • Read whether the add-on requires experiments, Beta APIs, or a newer Script API.
  • Test it in a copy of your world before using it in an important project.

Why compatibility varies

Minecraft Bedrock and Minecraft Education use add-ons made from behavior packs and resource packs. Files made for Java Edition loaders such as Forge, Fabric, or NeoForge will not work.

Minecraft Education uses the Bedrock add-on system, but it can run a different game version. A Bedrock add-on is therefore not automatically compatible with Education.

Using the editor

Instructions

Open a .mcworld file and change its game mode, difficulty, cheats, player permissions, world options, gamerules, experimental features, and enabled packs. Everything is processed locally in your browser.

How it works

  1. Export or locate your Minecraft world as a .mcworld file.
  2. Open it in the editor and change the settings you need.
  3. Save a modified copy and import it back into Minecraft.
Common questions

Frequently asked questions

Does my world get uploaded?

No. Your world is opened and modified locally in your browser. The editor downloads a new copy and leaves your original file untouched.

Which Minecraft versions are supported?

The editor is designed for Minecraft Bedrock Edition and Minecraft Education worlds exported as .mcworld files. Java Edition worlds are not supported. World formats can change between releases, so keep a backup and test the modified copy before relying on it.

Can this enable cheats and coordinates?

Yes. Cheats are available under Player access, and Show coordinates is under World options. Hardcore worlds keep cheats disabled because that is part of Hardcore mode.

Why do I only see certain experiment tags?

Minecraft only stores experiment tags that have been added to that world. The “In this world” list shows those stored tags, while “Available to add” contains known tags that the editor can add. The experiments used by Minecraft vary between versions.

Does disabling an experiment undo blocks or features already used?

No. Disabling a tag does not remove blocks, entities, or other experimental content already saved in the world. That content may stop working correctly when the experiment is disabled, so make a backup first.

Will changing the seed regenerate existing chunks?

No. Existing chunks stay as they are. The new seed only affects terrain generated in chunks that have not been visited before.

Can I use the editor on mobile or Chromebook?

Yes, in a modern browser that can open and download local files. The exact steps for importing the modified file back into Minecraft depend on your device and browser.

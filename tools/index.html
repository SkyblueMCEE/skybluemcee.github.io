What does this website have?

Minecraft Tools that run in your browser

  • Minecraft Education AND Bedrock compatibility! Most tools on this website will work on both Minecraft Education AND Minecraft Bedrock since they use the same type of files.
  • No Uploads. NOTHING is uploaded, and all your data is processed locally. Actions done in this tab stay in this tab. Don't believe me? Turn off your wifi and the tools still work.
  • No installs, and no accounts. You don't have to download or sign into anything. All tools will be available to you on your browser.
  • Open source. All tools are open source on GitHub. If you want to read the source code, you can!
